一期直接使用寻源通已有的商品相关性、筛选及排序能力，AC 不额外建设商品相似度和推荐模型。

1688寻源通负责
相关性与返回顺序
复用已有图搜、关键词搜索、筛选及排序能力。

组织输入、执行采购约束、管理候选，并落入供应商和待开发产品。
一期产出
≤ 10条 / ASIN
形成可查看、可选择、可生成、可维护且可追溯的正式关系。

一期包含

在调研中的开发任务内，对参考ASIN自动或手动发起1688溯源；展示候选及商详；选择offer和SKU后生成备选供应商、待开发SPU/SKU，并接入现有编辑和提交审核流程。

一期不建设

AC不建设商品相似度模型、综合推荐评分或二次排序模型。AI仅将Amazon品类、产品名称和基础属性清洗为中文搜索词，不参与商品相似度判断。

3. 触发与前置判断

3.1 触发时机

场景处理方式是否影响已有ASIN
新建任务并保存初始参考ASIN将本次保存的ASIN作为首批新增，每个ASIN独立初始化并执行自动溯源判断不适用
调研中任务新增一个ASIN仅处理本次新增ASIN不重新溯源已有ASIN
一次新增多个ASIN每个ASIN独立维护状态、候选数量、溯源时间和结果“全部ASIN”只做汇总更新

新增参考产品继续沿用开发任务现有权限：任务状态为“调研中”且当前用户为任务开发人。ASIN成功加入任务后，自动溯源属于系统动作，不再次要求用户确认。

3.2 自动溯源价格判断

参考产品数据最高采购价处理
已维护目标采购价区间取区间上限满足其他条件时自动溯源
未维护目标采购价，0%毛利推算采购价 > 0使用0%毛利推算采购价满足其他条件时自动溯源
目标采购价为0，且0%毛利推算采购价为空或 ≤ 0不可用不调用1688，状态记为“未自动溯源”，允许任务开发人手动不限价溯源

目标采购量 > 0时限制“起批量 ≤ 目标采购量”；目标采购量为0表示未维护，不传MOQ限制，页面展示“起批量不限”，且不影响自动溯源价格判断。

4. 溯源处理策略

4.1 核心接口编排

product.image.upload上传参考ASIN主图，取得图片搜索所需imageId。
product.search.imageQuery执行图片搜索，作为候选结果主序列。
product.search.keywordQuery使用AI清洗后的中文关键词补充召回。
product.search.queryProductDetail为最终候选补齐SKU、价格库存、属性、供应商、履约品质和发票信息。
ASIN图片与基础数据 → 图片上传 → 图搜主序列 + 关键词补充 → offerId合并去重 → 准入与采购约束 → 供应商限量 → 最终候选商详

4.2 货源准入与采购可行性

分组业务条件说明
货源准入跨境精选货源沿用原人工抓取实际规则
有跨境推广链接
商品体验分 > 4.0
采购可行性采购价不超过当前参考产品最高采购价AC结合当前开发任务增加的约束
目标采购量 > 0时，起批量不超过目标采购量
综合服务分、近30天品质退货率不作为一期硬筛选条件，仅在商品详情中作为辅助判断信息展示。

4.3 召回、合并与商详

  1. 图片搜索结果作为主序列，关键词结果用于补充；按offerId合并去重，并保留“图搜、关键词、图搜+关键词”的来源标记。
  2. 每个通道最多请求2页；候选不足10条时才继续请求下一页，达到10条、无更多结果或达到页数上限即停止，不放宽准入条件。
  3. 同一sellerOpenId最多保留2个商品，每个ASIN最终最多展示10条候选。
  4. 搜索阶段负责宽召回，商详阶段负责补齐；只对最终展示候选调用商品详情，避免对全部召回结果逐条查商详。
  5. 候选价格优先按商详SKU批发价展示单价或区间；缺少SKU明细时才回退搜索价格。

4.4 供应商匹配与时间

使用1688公司名称与内部供应商名称精确匹配；地址省市和“渠道-1688”类型仅作辅助校验。匹配成功保存内部供应商ID；未匹配候选在正式生成备选供应商后才按现有机制标记为临时供应商。

候选信息栏展示溯源数据获取时间，商品详情展示详情获取时间。刷新只读取AC后台数据，不调用1688、不更新时间；重新溯源才产生新批次并更新溯源时间。

5. 页面结构与状态

模块承担的信息主要操作
参考产品ASIN基础信息、目标采购量、目标采购价、溯源状态和候选数量查看货源；未自动溯源时由任务开发人发起手动不限价溯源
1688备选货源全部ASIN及单个ASIN候选、溯源条件、数据获取时间、商品与商家表现刷新、在具体ASIN Tab重新溯源、查看详情、选择货源、生成待开发产品
备选供应商内部匹配结果、临时供应商、来源沿用现有绑定和解绑能力
待开发产品生成或手动添加的SPU/SKU、供应商、参考产品、来源及采购信息编辑、删除、补充必填信息

5.1 参考产品与候选状态

  • 参考产品保留现有多选、分页和固定列；右侧固定列依次为目标采购量、目标采购价、1688溯源、操作。
  • 参考产品行内只提供“查看货源”快捷入口；“重新溯源”属于1688备选货源，在具体ASIN Tab下执行。
  • 当前任务没有参考产品时，候选模块展示“当前任务暂无参考产品 / 添加参考产品后，系统将自动发起1688溯源”。
  • 必须区分正在溯源、溯源完成0条、未自动溯源、溯源失败和已完成等状态。

5.2 条件信息栏、列表与详情

  • ASIN Tab下方只设置一条轻量信息栏：左侧使用业务中文展示溯源条件，右侧弱化展示数据获取时间；不向业务用户暴露接口字段名。
  • “全部ASIN”汇总所有参考产品的当前候选；具体ASIN Tab展示独立状态、条件、时间和结果。
  • 已经生成待开发产品的候选保留详情和原商品链接，但禁用复选框、轻微置灰并标记“已转待开发产品”。
  • 商品详情按商品概要与采购、SKU变体、商品表现、供应商与商家表现、履约品质、发票与属性分组。

候选列表复选框与详情底部“选择该货源 / 取消选择”同步，但勾选只形成页面临时集合；只有确认“生成待开发产品”后才写入正式业务数据。

6. 结果生成与维护

6.1 生成前确认

点击“生成待开发产品（N）”后打开“确认待开发变体”弹窗，按1688 offer分组展示SKU并默认全选。用户可取消无需开发的SKU；某offer选择0个SKU时不生成该SPU；全部SKU均未选择时确认按钮不可用。

1688数据生成结果取值规则
一个offer一个待开发SPU标题、主图、供应商及来源取该offer
一个被选中的1688 SKU该SPU下一个待开发SKU规格、SKU图、采购价和库存取对应变体
供应商一条备选供应商记录正式供应商按内部ID去重，临时供应商按sellerOpenId去重

6.2 正式关系与防重复

确认生成时保存“任务—参考ASIN—1688 offer—待开发产品”正式关系，并记录来源链接、溯源批次、供应商和操作人。同一任务 + ASIN + offerId禁止重复生成；重新溯源再次召回相同offer时，继续识别已有关系并标记为已转待开发产品。

6.3 备选供应商

匹配成功时直接关联内部正式供应商；未匹配时按现有机制生成临时供应商。供应商是任务级对象，可能同时关联多个SPU或手动添加产品，因此删除单个SPU时不自动解绑或删除供应商。

6.4 待开发产品维护

  • 列表和编辑弹窗共用同一份SPU/SKU数据，编辑和删除立即同步，不维护第二套示例数据。
  • 来源展示“1688备选货源 · 查看原商品 ↗”，链接使用跨境推广链接，不向用户展示offerId；手动创建仍显示“手动添加”。
  • 编辑弹窗沿用原业务字段；1688规格展示在产品标题下方，参考产品支持相同款/相似款，预生成产品未维护的系统品类和预计售价默认显示红色内联提示。
  • 预计售价区间未维护时，仅在SKU行对应字段显示“待维护”；候选及待开发产品长标题最多展示两行，悬浮查看全文。

7. 结果生命周期规则

以下规则统一说明刷新、重新溯源和删除动作分别影响哪些业务对象，避免候选数据与已生成数据相互覆盖。

动作1688候选待开发SPU/SKU备选供应商正式来源关系
刷新只读取AC后台当前数据，不调用1688、不更新时间不变不变不变
具体ASIN重新溯源使用相同规则建立新批次，直接覆盖该ASIN原候选及溯源时间已经生成的数据不变不变保留；同一offer再次召回时继续标记已转产品
删除SKU不变，不恢复候选只删除该SKU；即使删至0个也保留SPU不变保留SPU与offer关系
主动删除SPU若对应offer仍在当前候选中，则恢复可选删除SPU及其全部SKU不自动解绑或删除解除该SPU与offer关系
供应商不级联删除：同一供应商可能被多个SPU、多个offer或手动添加产品共用；同时还可能已经进入内部匹配和审核流程。因此删除SPU只解除产品与offer关系，供应商仍由现有绑定、解绑和人工清理机制管理。

删除SKU和SPU均需二次确认。SKU确认文案明确“保留SPU且不恢复货源”；SPU确认文案明确“同时删除全部SKU，并可能恢复对应1688候选”。

8. 权限与提交校验

用户与任务状态可执行操作
调研中 + 当前任务开发人新增参考ASIN、手动/重新溯源、选择货源、生成和维护待开发产品、删除SPU/SKU
调研中 + 管理员但不是任务开发人可查看、刷新及按现有权限删除参考产品；无标记权限，其他溯源和结果维护操作只读
其他查看人或非调研中状态只读，不允许新增参考产品或改变溯源及结果数据
所有拥有任务查看权限的用户可刷新并查看候选、详情、供应商、待开发产品、来源关系和原商品链接

提交校验

任一待开发产品仍有“待维护”、必填业务字段未完成、SPU下没有可提交SKU，或原有校验不通过时，不允许提交。统一提示“当前仍有待开发产品信息未维护，请处理完成后再提交”，并定位待开发产品模块；备选供应商继续执行原有提交校验。

A.2 接口调用约定

  • 图搜pageSize优先50；关键词搜索联调确认支持50时使用50，否则使用接口实际支持的最大值。搜索按页获取并逐页筛选，达到10条有效候选、接口无更多结果或达到安全页数上限时停止；安全上限一期暂按每通道2页设计，但不作为固定常量，研发实施时根据接口额度、平均命中率和耗时评估，并与产品共同确认最终配置。
  • 搜索接口返回offer级摘要价格，商品详情返回SKU价格，两者可以独立存在。候选优先展示有效SKU价格；没有有效SKU价格但搜索结果存在有效价格时展示搜索价格；两者都不存在时展示“--”，不得推算或填造价格。
  • 候选按offerId去重；正式供应商按internalSupplierId去重，临时供应商按sellerOpenId去重。
