重要：country 虽然名字像“国家”，官方定义实际是语言，例如 en。区域/商机参数不是必填，不传不会阻止普通搜索，也不会让基础商品字段消失。
返回模型 ≠ 一定有值：字段可能被省略、返回 null、空字符串或空数组。前后端必须按“字段可缺失”设计，不要把缺失直接转换为 0。

3. 鉴权与公共参数

参数必填类型含义
${APPKEY}必填URL 路径应用 AppKey。
_aop_signature必填String按 1688 AOP 规则生成的请求签名。

4. 多语言关键词搜索参数

顶层业务参数 offerQueryParam 必填，内部字段如下。

字段必填类型含义示例
keyword必填String搜索关键词。人体工学椅
beginPage必填Integer起始页码。1
pageSize必填Integer每页数量。20
country必填String语言代码，不是经营国家。en
filter可选String筛选标签，多个 tagKey 用英文逗号分隔。whiteBgImage,hasPatent
sort可选String(JSON)排序配置。{"price":"asc"}
outMemberId可选String调用方自己的终端用户标识，用于链路识别或分析；不是 1688 会员 ID，也不能代替鉴权。建议传匿名内部 ID，如 user-123；不需要区分终端用户时不传
priceStart / priceEnd可选String批发价范围。10 / 100
categoryId可选Long单个数字类目 ID；不得填写“类目id”等占位文字。1045585
categoryIdList可选String多个类目取并集，用英文逗号分隔。2,45
regionOpp可选String1688 区域商机场景枚举，用于限定目标市场商机；不是语言代码，也不是图片坐标。只能使用开发者菜单给出的枚举；第一期建议不传
productCollectionId可选String1688/寻源通配置的业务货盘（商品池）ID；传入后可能只在该货盘中搜索。174316138；不是 offerId、categoryId 或自建集合 ID
snId可选String1688 平台搜索导航节点或导航路径 ID，面向特定导航场景。978:1352；普通 API 关键词搜索不需要传
keywordTranslate可选Booleantrue 表示关键词已经翻译，服务端跳过翻译。false
saleFilterList可选Array按 sales7、sales14、sales30 或 totalSales 筛选销量区间；多个条件是 AND 交集，不是排序。[{"saleType":"sales7","saleStart":"10","saleEnd":"100"}]

最小请求

{
  "offerQueryParam": {
    "keyword": "人体工学椅",
    "beginPage": 1,
    "pageSize": 20,
    "country": "en"
  }
}
普通接入建议：regionOpp、productCollectionId、snId 都是特定平台业务场景参数，没有 1688 提供的合法值就不要传。需要销量门槛时再增加 saleFilterList，例如同时设置近 7 天和累计销量时，两项必须同时满足。

5. 多语言图片搜索参数

顶层业务参数 offerQueryParam 必填。当前官方字段模型将 imageId 标记为必填。

字段必填类型含义示例/注意
imageId必填String调用图片上传接口后生成的图片标识；不是文件名、URL 或哈希。上传接口的 result.result
beginPage必填Integer页码。1
pageSize必填Integer最大不超过 50，官方建议 20。20
country必填String语言代码。en
region可选String图片中参与图搜的主体裁剪区域，不是国家、市场或 regionOpp。4 个整数的坐标字符串；官方保存页未明确坐标顺序，优先沿用平台返回的区域格式，不要猜测拼接
filter可选String筛选标签，多个用英文逗号分隔。whiteBgImage,hasPatent
sort可选String(JSON)排序配置。{"price":"asc"}
outMemberId可选String你们系统里的终端用户标识，不是 1688 账号；可用于链路区分或分析。建议匿名化；不需要区分用户时不传
priceStart / priceEnd可选String批发价范围。10 / 20
categoryId可选Long数字类目 ID；建议用相似结果的 thirdCategoryId。坐垫实测：1046964
imageAddress可选String直接图片地址；官方仅保证 1688 图片链接场景。外部图片优先上传换取 imageId
keyword可选String在图搜结果中继续按词搜索。坐垫
auxiliaryText可选String图文联合检索的辅助描述，用颜色、材质、款式或用途帮助理解图片；是相关性提示，不是严格筛选条件。黑色 人体工学 坐垫；只找视觉同款时可不传
productCollectionId可选String寻源通工作台货盘 ID。—
keywordTranslate可选Boolean辅助搜索词是否已翻译。false
itemTitle可选String原商品标题，可提升图搜效果。—
 
{
  "offerQueryParam": {
    "imageId": "上传接口返回的图片ID",
    "beginPage": 1,
    "pageSize": 20,
    "country": "en",
    "categoryId": 1046964
  }
}
官方接口详情的某个顶层示例曾仅使用 imageAddress，但当前嵌套字段模型仍将 imageId 标为必填。生产接入建议以“上传图片 → imageId → 图搜”为主路径，将 imageAddress 作为 1688 图片链接的兼容路径。
关于 region：单主体、商品占画面较大的图片直接不传即可；只有图片中存在多个商品、人物或大面积背景，并且用户需要框选局部时才传。之前的黑色坐垫图主体明确，第一期不需要 region。

商家表现交易勋章 1，综合服务 4.5，物流 4.1，纠纷 5.0，商品 5.0，售后 5.0，复购小数约 0.178916复购小数按比例理解时约为 17.89%；展示前需统一百分比格式。

证书certificateList=[]本条商品没有返回证书信息，不能解释为已经完成合规认证。

附件完整性：当前粘贴文件在 invoiceInfo 后缺少最外层 JSON 的结束花括号，直接作为 JSON 解析会报错；这不影响判断本次 API 调用成功，但保存原始响应时应确保报文完整。

搜索与详情的推荐数据合并方式

搜索结果.offerId
  → queryProductDetail(offerId, country)
  → 用详情数据补齐 SKU、库存、属性、供应商名称、图文详情和物流数据
  → 保留搜索结果中的 traceInfo / promotionURL 用于点击归因

详情接口更完整，但仍不是完整企业工商档案接口。若后续需要营业执照主体、工厂资质或详细注册地址，应再确认是否具备供应商/会员详情能力。

7.3 根据关键词查叶子类目

alibaba.category.searchByKeyword 的业务参数只有一个必填字段：

{ "keyword": "护腰坐垫" }

返回 products[].categoryID、name、isLeaf。应选择语义最相关且 isLeaf=true 的类目。

不要混淆：商品链接中的 offerId 是商品 ID；店铺页面的“护腰/键盘护腕”等通常是店铺自定义分类；两者都不是平台 categoryId。

13. Pro 版实施建议

  1. 后端统一封装 AOP 签名、token、表单编码和错误解析。
  2. 为关键词和图搜分别定义强类型请求 DTO，必填字段在调用前校验。
  3. 所有响应字段按 optional 处理；区分“0、null、缺失、空字符串”。
  4. 百分数字符串去掉 % 后再计算；repeatPurchasePercent 还可能是 0~1 小数。
  5. 维护 AppKey 可用 tag 白名单，避免无权标签导致整次请求失败。
  6. Pro 履约字段设置数据时间、缺失状态和来源标记，不把缺失当 0。
  7. 图搜主链路使用 image upload → imageId；仅对 1688 图片链接尝试 imageAddress。
  8. 类目 ID 优先来自商品详情或搜索结果的 thirdCategoryId；不要使用 offerId 和店铺分类。
  9. 商品卡片至少保留 offerId、标题、图片、价格、promotionURL、类目和 traceInfo。
  10. 对负向履约 tag（fakeShip7d 等）先进行小流量测试，确认其筛选极性。
  11. 上线前让 1688 运营确认 Pro 权益、经营市场、AppKey 控制配置和 GMV 升降级门槛。
  12. 监控业务 code、字段缺失率、空结果率、类目分布和异常 totalPage。
推荐第一阶段：先接入关键词搜索、图搜、图片上传和商详；使用 Pro 履约字段做展示与排序辅助；只开放已确认权限且语义明确的标签。区域经营标签在运营确定目标市场后再开启。

14. 常见问题速查

问题结论
国家或区域是不是必传？country 必传，但它实际表示返回语言；关键词的 regionOpp 和图搜的 region 都是可选字段，且两者含义完全不同。
不传区域是不是就没有区域数据？不传 regionOpp 只表示不按区域商机场景限制搜索；Pro 区域经营能力主要通过有权限的市场标签筛选，并不是普通响应自动返回一组各国 GMV 数据。
没有 1688 图片，imageId 怎么来？把本地/外部图片转为纯 Base64，调用 product.image.upload，读取上传响应的 result.result 作为 imageId，再调用图搜。
categoryId 可选，但测试工具删不掉怎么办？不能填写“类目id”等文字占位符，因为它是 Long。可传搜索/详情中的 thirdCategoryId；工具确实无法删除时，尝试清空或填真实数字，不能用中文占位。
搜索后还要等用户点击才能拿 offerId 吗？不需要，搜索结果已经有 offerId。用户点击只是推荐的按需查详情触发点，用来减少 N+1 调用；业务需要时也可以搜索后立即补查。
搜索结果为什么没有供应商名称？搜索是摘要接口，字段可能缺失。本次 offerId 1084127309764 的详情成功补出 companyName=苍南县新敏百货商行；完整工商档案仍可能需要供应商/会员接口。
promotionURL 是商品详情页吗？是，而且通常包含来源归因参数。优先保留搜索返回的 promotionURL；详情接口对应字段写作 promotionUrl，大小写不同。
AIGC 图能当真实商品图吗？不建议。它是 AI 处理的备选展示图，具体处理方式不固定且经常缺失；真实商品展示默认使用 imageUrl。
普票、专票和纳税人类型有什么用？用于企业采购报销、抵扣与合规初筛。接口值不构成正式开票承诺，缺失或线上开票为 false 时仍应向供应商确认。
详情里的重量尺寸能直接计算运费吗？不能无条件使用。本次坐垫返回 5 克、长宽高为 0 且来源“商家自填”，明显异常；跨境报价前必须校验并向供应商确认包装后毛重和尺寸。
